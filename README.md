# sdr - 📺
My take on the original [sd](https://github.com/ianthehenry/sd) by Ian Henry.
Read [his blog](https://ianthehenry.com/posts/a-cozy-nest-for-your-scripts/) for an introduction.

To make things easier for myself I did this in Rust instead of pure bash.
I use the same folder structure and location so no migration necessary.

## Praise for `sd`
For some reason `sd` just really *clicked* for me and I've been wondering why that is.
The best I've come up with so far is that it neatly separates my hacky, personal scripts from other more mature/professional executables (even those I made myself).

Having this clear separation allows me to stop worrying about polluting my `$PATH` ("*is this good enough yet?*") and just write my scripts.
Will I ever use them? Doesn't matter, benefits of varying size if I do and no biggie if I don't.
